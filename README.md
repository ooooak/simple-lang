----


typical compiler Pipeline

Lexer (Lexical Analysis) - Converts source code into tokens
Parser (Syntax Analysis) - Converts tokens into an Abstract Syntax Tree (AST)
Semantic Analyzer - Checks types, scopes, and meaning
Intermediate Code Generator - Creates intermediate representation (IR)
Optimizer - Optimizes the IR
Code Generator - Generates target code (assembly/machine code)
